A short relaxing text for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.py` writes one text (266 characters) to `/output/entry.txt`: a quiet
image of the tide coming in over flat sand under a moon with nowhere to be —
written to slow the reader down, showing rather than instructing, with one
vast thought that keeps growing after the last line.

Run it with:

```sh
python3 main.py
```
